Appendix B · what this setup can and cannot show
  • The world has one rule and two gates, so a flipped rule always means the other gate.
  • Muse sees the world version label, and it changes exactly when the rule flips. Using a memory well and reading the label are not yet separable.
  • The inspection hint is fixed per seed and world, and is wrong for about one in four. Some seeds get a wrong hint in both worlds.
  • Verified makes one extra model call. Each strategy is sampled once per world, so no ranking of strategies is claimed.
  • Reservations limit calls and output tokens inside this process. They do not cap CPU, RAM or spending.
