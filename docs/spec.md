# AMADEUS — SECOND DAWN: RE

## Goal

Show real Muse decisions in deterministic changing worlds and compare how different memory policies behave. This is an interactive experiment, not a claim of consciousness or scientific proof.

## Acceptance

- Muse selects schema-validated actions; the server independently evaluates every transition and outcome.
- A reproducible generation can terminate and restart while retaining attributed, evidence-backed memories.
- At least two world versions preserve some rules and change others.
- Compare no memory, unverified memory and applicability-checked memory under matched starting conditions; report raw outcomes and limitations without fabricated runs.
- Show generations, events, deaths, decisions, memories and results; protect server-side API credentials.
- Tests, instructions, and reproducible walkthrough accompany the implementation.
- Compare policies with a mode that equalizes the fallible inspection and its cost; expose remaining differences.
- Provide a bounded exact preview for selecting candidates under declared multidimensional reservations, without presenting it as live resource enforcement.
- Link a recorded v1 generation to a v2 child with the same seed; the verified continuation must assess attributed parent evidence through the model before acting and persist the actual assessment, action, independent outcome and provenance. No automatic or simulated model call is presented as real.

## Constraints

Small local modular monolith; bounded calls and tokens. No distributed platform. Meta API failure must be visible, never disguised as a real decision. Do not touch Aeontra.

## Practical continuity slice

A user can preserve an explicit work objective and selected text files from a configured workspace, restart the process, inspect actual file changes and request a Muse assessment with source quotations checked by the backend. This is a read-only continuity assistant, not autonomous execution. Explicitly disclose that selected content is stored locally and transmitted to Meta; restrict paths, file types and sizes, reject likely credentials, and explain that secret detection is not exhaustive.
